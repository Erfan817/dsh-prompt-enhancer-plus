# 提示词预览 · 透明化规格

> 状态：已实施于 `client.js`（Prompt Spark 插件的「提示词预览」面板）。
> 范围：**仅提示词预览插件自身的预览面板**（`.pe-overlay` 与 `.pe-workspace`）。
> **不修改 DSH 全局主题、桌面伴侣窗口、VS Code/Cursor 扩展面板。**

---

## 1. 目标

透过预览面板能**隐约看到背后的文字**，形成轻量透视感；同时 DSH 其他区域保持原样、清晰，不出现整屏毛玻璃或模糊。

## 2. 具体参数

| 元素 | 处理 |
| --- | --- |
| `.pe-overlay`（遮罩层） | **完全透明**，无 `backdrop-filter`，不模糊也不压暗背后的 DSH 画面 |
| `.pe-workspace`（预览主面板） | `--dsw-alias-bg-overlay` **86%** 不透明度，无模糊；背后文字以约 14% 强度隐约透出 |
| `.pe-workspace` 边框 | 55% 半透明细边框 |
| `.pe-workspace` 圆角 / 阴影 | 14px / 原有柔和阴影 |

关键点：没有 `backdrop-filter`，因为一旦加模糊，背后的文字就会被抹掉，只剩毛玻璃效果——这正是要避免的。

## 3. 可读性保障

- 文字颜色仍使用 `--dsw-alias-label-primary`，不叠加透明度。
- 输入框、按钮、操作条保持原有实色/高对比样式。
- 面板 86% 不透明度已保证正文对比度，同时保留轻微背景可见度。
- 不改变 DSH 其他区域的任何样式或过滤效果。

## 4. 验收

- [ ] 打开「提示词预览」，可透过面板隐约看到背后的文字/界面。
- [ ] DSH 其他区域保持原有清晰度，无整屏模糊或毛玻璃。
- [ ] 预览正文、按钮、输入区域清晰可读、可操作。
- [ ] 关闭预览后原界面完全恢复。

## 5. 回滚

将 `client.js` 中两条样式恢复为改动前的值即可：

```css
.pe-overlay { background: color-mix(in srgb, var(--dsw-alias-bg-base) 78%, transparent); }
.pe-workspace { border-radius: 10px; background: var(--dsw-alias-bg-overlay); }
```
