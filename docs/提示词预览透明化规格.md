# 提示词预览 · 视觉对齐规格

> 状态：已实施于 `client.js`（Prompt Spark 插件的「提示词预览」面板）。
> 目标：消除「廉价感 / AI 味 / 与 DSH 原版不搭」，全部对齐 DSH 主题 token。
> 范围：**仅提示词预览插件自身的预览面板**；不修改 DSH 全局主题、桌面伴侣窗口、VS Code/Cursor 扩展面板。

---

## 1. 对齐 DSH 主题 token（按优先级）

| 优先级 | 元素 | 改动 | 针对问题 |
| --- | --- | --- | --- |
| P0 | `.pe-workspace` 阴影 | `0 16px 64px` → `var(--dsw-elevation-panel)` | 廉价感 / 与原版不搭 |
| P0 | 面板边框 | `1px 55% 透明` → `.5px solid var(--dsw-alias-border-l1)` | 廉价感 / 与原版不搭 |
| P0 | 面板圆角 | `14px` → `var(--dsw-radius-lg)` (16px)；头尾同系 | 与原版不搭（14px 不在 8/12/16/20/28 体系） |
| P1 | 面板/正文表面 | 自定义 96% / 86% `color-mix` → `var(--dsw-alias-bg-overlay)`；头尾/人格栏用 `var(--dsw-alias-bg-layer-1)` | 与原版不搭 + 亮/暗偏色 |
| P1 | 控件圆角 | 按钮 `.pe-*` `5px` → `var(--dsw-radius-sm)` (8px) | 廉价感 |
| P2 | 玻璃/渐变 | 删除全部 `color-mix` 半透明层与 `backdrop-filter`；不再整块半透明 | AI 味 |
| P2 | 右侧人格栏 | 与主面板同一套 bg / border / radius token | AI 味 + 廉价感 |
| P3 | 字号 | 辅助文字统一 `13px/20px`；预览正文 `15px` → `14px` | 廉价感（细节不齐） |
| P3 | 间距 | gap / padding 收齐到 4px 网格（4/8/12/16/24） | 廉价感 |
| P3 | 分隔线 | 各处 `1px solid` → `.5px solid` | 与原版不搭 |

## 2. 保留项

- 文字颜色仍用 `--dsw-alias-label-primary` / `-secondary`，不叠加透明度。
- 输入框、按钮、操作条使用 DSH token 背景与边框，保持高对比、可操作。
- 遮罩 `.pe-overlay` 完全透明、无模糊，DSH 其他区域不受影响。
- 右侧人格栏（强化人格下拉 + 管理按钮 + 保存本次方向）位于预览面板内部右侧；窄窗口（≤900px）移到正文下方。
- 无「全屏」按钮及全屏状态。

## 3. 验收

- [ ] 预览面板阴影轻、边缘利落，不再是「浮在空中的大卡片」。
- [ ] 面板圆角、按钮圆角与 DSH 原生控件一致。
- [ ] 亮色 / 暗色主题下表面颜色自然，无发灰或偏色。
- [ ] 正文清晰可读，控件可正常操作。
- [ ] DSH 其他区域保持原样，无整屏模糊或毛玻璃。

## 4. 回滚

`git revert` 对应提交，或把 `client.js` 的 `STYLES` 恢复为改动前版本。
