# 提示词预览 · 透明化规格

> 状态：已实施于 `client.js`（Prompt Spark 插件的「提示词预览」面板）。
> 范围：**仅提示词预览插件自身的预览界面**（`.pe-overlay` 遮罩与 `.pe-workspace` 主面板）。
> **不修改 DSH 全局主题、桌面伴侣窗口、VS Code/Cursor 扩展面板。**

---

## 1. 透明化范围

| 元素 | 处理 |
| --- | --- |
| 预览遮罩 `.pe-overlay` | 半透明 + 背景模糊，让背后的 DSH 界面透出 |
| 预览主面板 `.pe-workspace` | 半透明 + 玻璃模糊，圆角与半透明边框 |
| 面板内部文字、按钮、输入框 | 保持不透明/高对比，不受透明影响 |
| 预览内部细节区、历史记录 | 保持实色/高对比 |

## 2. 具体参数

| 元素 | 变化前 | 变化后 |
| --- | --- | --- |
| `.pe-overlay` 背景 | `--dsw-alias-bg-base` 78% | **25%** + `blur(20px) saturate(1.15)` |
| `.pe-workspace` 背景 | `--dsw-alias-bg-overlay` 实色 | **55%** + `blur(24px) saturate(1.15)` |
| `.pe-workspace` 边框 | `--dsw-alias-border-l1` 实色 | 50% 半透明 |
| `.pe-workspace` 圆角 | 10px | 14px |

## 3. 可读性保障

- 文字颜色仍使用 `--dsw-alias-label-primary`，不叠加透明度。
- 预览区域内的输入框、按钮、操作条保持原有实色/高对比样式。
- 面板使用 `backdrop-filter` 对背后内容做强模糊，避免杂乱背景干扰阅读。
- 预览正文区域背景由面板 62% 半透明层承载，仍保持足够对比。
- 若宿主不支持 `backdrop-filter`，回退为更实的背景色（浏览器会自动忽略该属性，面板仍是 62% 半透明，可读性不受影响）。

## 4. 验收

- [ ] 打开「提示词预览」，能透过面板看到背后的 DSH 界面（模糊后）。
- [ ] 预览正文、按钮、输入区域清晰可读、可操作。
- [ ] DSH 主界面、桌面伴侣、VS Code 扩展的界面**没有**被改动。
- [ ] 关闭预览后，原界面完全恢复。

## 5. 回滚

将 `client.js` 中 `.pe-overlay` 与 `.pe-workspace` 两条样式恢复为改动前的值即可：

```css
.pe-overlay { background: color-mix(in srgb, var(--dsw-alias-bg-base) 78%, transparent); }
.pe-workspace { border-radius: 10px; background: var(--dsw-alias-bg-overlay); }
```
