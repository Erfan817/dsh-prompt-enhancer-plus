# 提示词预览 · 透明化规格

> 状态：已实施于 `client.js`（Prompt Spark 插件的「提示词预览」面板）。
> 范围：**仅提示词预览插件自身的预览面板**（`.pe-overlay`、`.pe-workspace` 及其头/体/脚）。
> **不修改 DSH 全局主题、桌面伴侣窗口、VS Code/Cursor 扩展面板。**

---

## 1. 目标

阅读区清晰优先，同时保留轻盈的玻璃层次：正文区域接近实色，标题栏与底部操作条保留半透明，遮罩不模糊、不压暗 DSH 其他区域。

## 2. 具体参数

| 元素 | 处理 |
| --- | --- |
| `.pe-overlay`（遮罩层） | **完全透明**，无 `backdrop-filter`，不模糊也不压暗背后的 DSH 画面 |
| `.pe-workspace`（面板外壳） | 背景透明（由内部区域着色），55% 半透明细边框，14px 圆角，柔和阴影 |
| `.pe-workspace-head`（标题栏） | `--dsw-alias-bg-overlay` **86%** 不透明度 |
| `.pe-workspace-footer`（底部操作条） | `--dsw-alias-bg-overlay` **86%** 不透明度 |
| `.pe-workspace-body`（正文阅读/编辑区） | `--dsw-alias-bg-overlay` **96%** 不透明度，保证长文本清晰 |

关键点：没有 `backdrop-filter`，避免整屏毛玻璃；透明只出现在装饰性头尾，阅读区接近实色。

## 3. 可读性保障

- 文字颜色仍使用 `--dsw-alias-label-primary`，不叠加透明度。
- 输入框、按钮、操作条保持原有实色/高对比样式。
- 正文阅读区 96% 不透明度，长提示词清晰可读。
- 不改变 DSH 其他区域的任何样式或过滤效果。

## 4. 验收

- [ ] 正文区域清晰，不再受背后文字干扰。
- [ ] 标题栏/底部操作条保留轻微玻璃感。
- [ ] DSH 其他区域保持原有清晰度，无整屏模糊或毛玻璃。
- [ ] 预览正文、按钮、输入区域清晰可读、可操作。
- [ ] 关闭预览后原界面完全恢复。

## 5. 回滚

将 `client.js` 中相关样式恢复为改动前的值即可：

```css
.pe-overlay { background: color-mix(in srgb, var(--dsw-alias-bg-base) 78%, transparent); }
.pe-workspace { border-radius: 10px; background: var(--dsw-alias-bg-overlay); }
```
