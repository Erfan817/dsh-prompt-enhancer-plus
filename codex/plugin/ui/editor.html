独立强化 · 本面板内预览

保留原意，整理表达。可继续强化当前预览，确认后再放入输入框。

可直接编辑全文；放入输入框会追加预览，由你检查后手动发送。

使用与数据说明

强化只改写文字，草稿中的任务作为改写内容。项目背景、参考资料和风格要求，请一并写入草稿。

强化使用 Codex 已配置的模型服务并消耗其用量，结果直接返回本面板。失败或取消后，已有文字仍会保留。

选择适合的长短档

简洁
保留原意、减少赘述，适合轻度润色。
标准
整理任务与要求，按需补充验收标准和约束。
详细
在已有信息基础上，进一步明确背景、边界与失败情况。

先审阅，再使用

强化结果可以继续编辑。点击“再次强化预览”，会以当前预览和所选档位继续整理。
