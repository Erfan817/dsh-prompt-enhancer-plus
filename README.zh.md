# Prompt Spark · 提示词火花

[English](README.md) · 中文

当前源码版本：**1.4.0**。GitHub Release 和 npm 独立发布，源码更新不代表已发布新的安装包版本。

项目现已更名为 **Prompt Spark（提示词火花）**。为兼容已有安装，DSH 插件及 npm 包标识仍保留 `dsh-prompt-enhancer-plus`。

一个增强核心，两种入口：在 DeepSeek Harness 中直接强化草稿，或用独立桌面窗口生成提示词，再复制到 Claude、Codex 及其他 AI 软件。不会自动发送消息。

## 1.4 的变化

- **正文优先**：DSH 预览改为大窗口，支持放大、全文阅读与编辑；不再把结果锁在六行小框里。长文使用正文区域的一层滚动，不承诺无限长内容能同时塞进一屏。
- **自然表达**：默认生成自然纯文本，避免井号标题、星号加粗、装饰列表和固定模板；Markdown 是明确可选的输出格式。
- **适度强化**：保留原语言、事实、范围和用户的口吻，不把所有请求当作编程任务，也不为了“强化”擅自扩写需求。
- **通用入口**：新增独立本机窗口，默认用 Node.js 和你已有的浏览器运行，不依赖 Electron；支持全文编辑、复制、全屏与取消生成。全局快捷键和置顶保留在可选的 Electron 开发入口。
- **共用规则**：DSH 与桌面助手使用同一个无 DSH 依赖的 `prompt-core.js`，复用五个内置强化方向。

原有自定义人格库、草稿版本保护、最近五条历史、替换后十秒撤销继续保留。

## 在 DSH 中使用

1. 写下你的任务，点击输入框工具栏中的 **强化提示词**。
2. 在大窗口中阅读全文。可直接修改结果，复制和替换使用同一份当前文字。
3. 按需要选择通用强化、系统提示词、任务描述或简洁润色，以及自然纯文本 / Markdown。重新生成会再次调用模型并消耗相应额度。
4. 点击 **替换草稿**，或者只复制结果。插件不会替你发送；替换后的十秒内可撤销。
5. 如果原始草稿已修改、改过再恢复，或者输入框正在发送，旧的插入版本会被拒绝，不覆盖新内容。

预览的人格管理、最近记录和模型用量属于次级信息，正文不再被这些控件挤成小框。Escape 关闭面板。

### “强化人格”是什么

它是告诉插件“如何改写”的可复用方向，不是本次具体任务。例如：

> 你是一名务实的产品经理。把我的想法补成有边界、可验收的需求。信息不足时指出待确认项，不增加无关功能，不编造数据。

内置通用助手、产品经理、工程审查、写作教练、极简编辑五个方向。内置方向只读，可复制为自定义；自定义人格可编辑、删除，删除当前选择时回退到通用助手。删除需要确认。

**将本次强化方向保存为人格** 复制本次请求捕获的方向快照，让你编辑后明确保存；不把任务或模型结果误当作人格，也不额外调用模型。旧记录缺少方向快照时仍可查看、复制、替换，但不能自动从正文推断人格。

模式决定输出类型，人格决定领域和风格。人格只用于辅助增强请求，不改变主助手、权限、聊天历史或主会话系统提示。

## 在 Claude、Codex 或其他桌面软件旁使用

这里的“通用”指 **同一个助手生成的结果可在不同软件使用**，不是将 Cordis 插件原样安装到所有客户端。

### 启动

从本仓库根目录执行，建议使用 Node.js 22 或更新版本：

```powershell
npm install --ignore-scripts
npm run desktop
```

Windows 也可直接双击根目录的 **启动通用窗口.cmd**。默认入口不再依赖 Electron，也不需要下载额外浏览器。它只监听本机 `127.0.0.1` 的随机端口，并打开系统默认浏览器；如果浏览器未自动打开，手动打开终端显示的本机地址。

1. 首次打开 **设置**，填写 API 基础地址、模型 ID 和你自己的 API Key。
2. 输入或粘贴原文，选择强化方式和方向，点击生成。
3. 阅读、编辑结果，点击 **复制全文**，切回目标客户端手动粘贴。
4. `Ctrl / Cmd + Enter` 生成。本机浏览器入口不提供全局快捷键或原生置顶，不读取其他软件的输入框。
5. 保持启动终端运行。关闭标签页不会自动结束服务，需点击界面 **退出** 或在终端按 `Ctrl+C`；退出后任务正文和内存中的 Key 不会恢复。

可选的 Electron 原生开发入口仍保留，支持全局快捷键、置顶与关闭后隐藏，但当前机器已确认有原生启动崩溃，不是默认启动方式：

```powershell
npm run desktop:setup
npm run desktop:electron
```

`desktop:setup` 仅为这个可选入口安装 Electron 并下载对应系统运行时；DSH 和默认通用窗口不需要它。不要通过关闭沙箱或修改系统权限来绕过原生启动错误。

### 模型接入

支持两类接口：

| 类型 | API 基础地址示例 | 模型 ID |
| --- | --- | --- |
| DeepSeek / OpenAI 兼容 | `https://api.deepseek.com` 或 `https://api.openai.com/v1` | 按服务商填写 |
| 本机 OpenAI 兼容模型 | `http://localhost:1234/v1` | 按本机服务填写，可不填 Key |
| Anthropic Messages | `https://api.anthropic.com/v1` | 按 Anthropic 控制台填写 |

基础地址也可填写完整的 `/chat/completions` 或 `/messages` 地址。远程必须 HTTPS，本机 `localhost`、`127.0.0.1` 和 `::1` 可使用 HTTP。为防止认证头跟随重定向泄露，桌面请求不跟随 API 重定向。

桌面版目前使用非流式文本请求，输出上限 3000 tokens，输入上限 12000 字符，超时 90 秒。不兼容 Chat Completions 或 Messages 的服务需要另写适配器；部分要求专用参数的模型也可能拒绝请求。达到输出上限、工具调用或非正常结束不会被当作完整成功。

**使用位置和增强模型彼此独立**：可以用 DeepSeek 强化，再交给 Claude 或 Codex 执行。不自动共享任何客户端订阅、Cookie 或登录状态；需要按服务商正式支持的方式接入和计费。

### 桌面隐私与密钥

- 不读取其他软件的输入框、剪贴板、凭据或用户配置。只有点击“复制全文”时才写入剪贴板，不自动粘贴或发送。
- 只有明确点击生成才会把原文和强化方向发送给已配置的模型 API；保存设置和切换方向不调用模型。
- 默认本机窗口的 Key 只在本次服务进程内存中使用，不持久化。仅可选的 Electron 入口提供 `safeStorage` 系统加密保存；安全存储不可用或只有 Linux `basic_text` 时拒绝持久化，不回退为明文。
- 已保存或在内存中的 Key 不返回给页面。切换接口类型或 API 地址时，若没有重新输入 Key，会清空旧 Key，避免误发给新服务。
- 独立助手仅保存非敏感模型配置、默认方向和你明确填写的自定义强化方向，不保存任务历史。通用窗口设置与 DSH 自定义人格库独立，本轮没有自动迁移或同步 DSH 数据。
- 本机服务严格校验 Host、Origin 与随机认证令牌，不开启 CORS，不对局域网监听。静态文件只有白名单；页面禁止被其他网站嵌入，模型网络请求只由 Node 后端执行。
- 可选 Electron 渲染器禁止 Node.js、开启隔离和沙箱，外部导航和新窗口被拒绝。

### 当前跨端边界

本轮提供的是独立本机网页窗口与 DSH 原生入口，不包括 Claude / Codex 的原生输入框插件、MCP 服务、MCP Apps 或自动草稿读写。以后可基于共享核心另加适配，但每个宿主仍需独立验证。默认窗口可在桌面浏览器中使用，源代码面向 Windows / macOS / Linux；没有承诺各操作系统已完成视觉验收，也未制作签名安装器。

## 纯文本与符号保真

默认格式由生成规则约束：用自然段表达，不添加 Markdown 装饰，不强迫“角色 / 目标 / 约束 / 输出”的结构。用户任务里要求的交付格式仍保留，例如“写一个 Markdown 文档”不会被改成“不要用 Markdown”。

兜底清理只处理可识别的模型外包装与新增的明确标题装饰，不会全局删除星号、井号或反引号。`C#`、`*.ts`、标签、命令、公式、代码和原文中的有意义例子需要保留。模型规则不是对任意输出的数学保证；保真不确定时宁可保留符号，由你在预览中核对。

## DSH 安装与配置

发布版仍以仓库 / npm 实际版本为准。源码目录可通过 DSH 插件管理器安装；本地目录安装建立链接，请不要再移动或删除源目录。修改已加载的 Host 模块可能需要重启 DSH，刷新页面不一定能加载新的 Host 代际。

现有配置继续支持：

```yaml
- id: prompt-enhancer-plus
  name: dsh-prompt-enhancer-plus
  config:
    maxInputChars: 12000
    maxOutputTokens: 3000
    timeoutMs: 90000
    systemPrompt: |
      Rewrite the request as a concise task brief.
```

需要 DSH 0.2.2-rc.1 或兼容更新版本，Host 提供 `connection`、`llm`、`agents`、`agentDefaultModel`、`storageDomain`。现有图标为插件保留的原创闪光图形，未借用第三方品牌图标。

`systemPrompt` 仍替换内置模式提示，之后叠加所选人格。格式、语言、事实、范围和只改写不执行的基础规则最后追加，并优先于冲突的自定义方向。默认不新增模型调用次数。

### API 与工具

`POST /api/prompt-enhancer-plus/enhance` 保持 `text`、`sessionId`、`mode`、`personaId`，新增可选 `format: "plain" | "markdown"`，缺省 `plain`。响应保持原来的文本、用量、耗时、模型和人格快照字段，并增加 `format`。

人格接口继续复用 Host 认证：`GET /api/prompt-enhancer-plus/personas` 读取；`POST` 支持 `list`、`save`、`select`、`delete`，修改需要最新 `expectedRevision`。

`prompt_enhancer` 工具调用同一应用操作。先 `list` 获取版本再修改人格；`enhance` 接受可选 `format`。工具不发送消息、不替换输入框、不改权限。

共享核心导出 `resolveMode`、`resolveFormat`、`enhancementSystem`、`inputFor`、`normalizeEnhancedText`，也可通过包子路径 `dsh-prompt-enhancer-plus/core` 引用。无 DSH、Node 或模型 SDK 依赖。

## DSH 存储与兼容

- 自定义人格与默认选择通过 Host `storageDomain` 保存在 `prompt_enhancer_plus_personas`，同一 Host 跨会话复用，不手工改写 profile。
- 最多 50 个自定义人格；名称 1–60 字符，单方向字段 4000 字符，所有方向合计 10000 字符。并发冲突时保留表单并要求重新核对，失败不报成功。
- 最近五条任务历史仍在浏览器 localStorage 按会话保存，可能包含输入和结果。没有迁移、上传或清除旧历史；端口变化时旧浏览器历史可能不可见。
- 1.2.x / 1.3.x 历史缺少格式时按旧文本读取，不重新生成，不悄悄改写已保存正文。
- 草稿引用 chip 和附件内容仍不由强化模型理解；全文替换属于纯文本编辑，应核对引用。

## 开发与验证

```powershell
npm install --ignore-scripts
npm test
node --check index.js
node --check client.js
npm pack --dry-run
npm run desktop:smoke
```

`npm test` 不需要 Electron，也不访问真实模型：覆盖核心规则与符号保真、Host / Tool 兼容、人格库、客户端纯状态、模型 API 适配、密钥存储与本机 HTTP 服务安全。`desktop:smoke` 启动真实 Node 本机服务并检查页面和认证初始化，不打开浏览器、不截图、不调用模型，并清理独立临时配置。可选原生入口的启动检查另用 `npm run desktop:electron:smoke`，当前未通过。

自动测试不是视觉验收。需人工检查浅深色、窄窗口、长文全文编辑、焦点与 Escape，以及实际服务商 API。不要把安装成功或 Slot 注册成功等同于已经看过最终界面。
